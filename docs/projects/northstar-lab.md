\# Northstar Enterprises: Enterprise Security Engineering Lab



\*\*Status: planning and early setup.\*\* Nothing on this page is a completed implementation. It describes what I intend to build, and I will update it as components are finished.



\## Vision



Northstar is a planned enterprise-inspired hybrid security environment for a fictional company. The goal is to simulate security challenges across one environment and to show how several security disciplines work together, from identity and endpoint security to detection, response, and AI-assisted operations.



\## Planned areas



\- Enterprise cloud and hybrid infrastructure

\- SIEM operations, detection engineering, and threat hunting

\- Identity and access security, Active Directory, and Group Policy

\- Endpoint telemetry and investigation

\- Application-layer security and insider-threat investigations

\- Threat intelligence and deception technology

\- Security orchestration, automation, and incident response

\- AI-assisted SOC operations

\- AI red-teaming and regression-based security validation



\## Planned technologies



Microsoft Sentinel, Microsoft Defender, Azure, Azure Arc, Active Directory, Sysmon, OWASP Juice Shop, and PyRIT.



\## Current progress



I am currently preparing the infrastructure, starting with the server that will host the OWASP Juice Shop application. No other components have been completed yet.
