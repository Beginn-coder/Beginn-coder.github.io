\# Additional Security Labs



Hands-on labs and learning implementations covering different areas of cybersecurity. Each one is based on a guided tutorial or learning resource, credited below. They document hands-on practice and technical development, not independent production implementations.



\## SOC Automation Lab



\*\*Based on:\*\* a guided tutorial from MyDFIR.



Explores SIEM monitoring, alerting, and incident response automation using Wazuh, Shuffle, and TheHive.



[View the repository](https://github.com/Beginn-coder/SOC-Automation-Lab)



\## SOC Automation Project 2.0



\*\*Based on:\*\* a guided tutorial from MyDFIR.



Explores security monitoring and automated response workflows. The environment from this lab also served as the base for my [AI-Assisted Detection Engineering & Incident Response](/projects/ai-detection-engineering) project.



[View the repository](https://github.com/Beginn-coder/SOC-Automation-Project-2.0)
